# Lot D2 — Exports Word, PowerPoint, PDF

## Fait
- `app/export/common.py` : citations `[n]` par ordre d'apparition, table des sources (document, page, section, extrait ≤ 200 car.), SHA-256 du contenu, `ExportForbidden` (état ≠ approved, vérifié dans `export_deliverable`/`load_export_data`), enregistrement dans `exports` + `audit`.
- `docx_export.py` (document de référence `reference/{type}-fr.docx` généré par `scripts/build_reference_docx.py`, annexe Sources, pied de page version/empreinte/approbateur/date, tableau d'initiatives + matrice constats → initiatives), `pptx_export.py` (titre, synthèse, une diapositive par vague, Gantt en formes, matrice de priorité), `pdf_export.py` (soffice, 60 s, sinon `ExportUnavailable`).
- `app/api/routes_export.py` : `POST /deliverables/{id}/exports` `{format: docx|pptx|pdf}` → fichier ; 403 non approuvé, 501 sans soffice, 422 format, 404 inconnu/autre dossier.

## Écarts aux contrats de 06
- Pas de méthode de dépôt pour `exports` ni pour lire l'état/l'approbateur : accès direct à `repo.engine` + `storage.schema` (comme `services/ingestion.py`).
- Pied de page : l'approbateur est l'id utilisateur (pas de nom affichable disponible).
- Pas d'enregistrement `exports.path` relatif : chemin absolu.

## Pour comprendre
L'export est la mise sous scellé d'un dossier : le greffier (le service) refuse tout document non signé, numérote les pièces citées dans l'ordre où le texte les invoque, joint l'inventaire (annexe Sources) et appose sur chaque page un tampon (version, empreinte, signataire, date) permettant de détecter toute altération.
