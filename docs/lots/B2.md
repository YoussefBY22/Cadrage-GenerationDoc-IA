## Limites
- PDF : titres détectés uniquement par numérotation (« 2.1 Gouvernance ») ; pas d'OCR (PDF scanné → avertissement « aucun texte »). Pas de colonnes multiples ni tableaux PDF.
- DOCX : pas de numéros de page (None) ; en-têtes/pieds ignorés. PPTX : notes ajoutées au bloc de la diapo.
- `scan` détecte HIDDEN_TEXT au texte seulement via ≥ 3 caractères de largeur nulle ; le cas « police minuscule » passe par les `warnings` du parseur PDF (le texte seul ne porte pas la taille).
- Taille max 50 Mo ; PDF chiffré → ParseError.

## Pour comprendre
Un parseur est un douanier : il regarde le passeport (extension) **et** le visage (signature) avant de laisser passer, puis range le contenu en blocs étiquetés page/section, comme des fiches de bibliothèque. `scan` est le détecteur de métaux : il signale sans confisquer (le passage reste cherchable). `neutralize` est le sas de décontamination avant d'entrer dans le prompt.
