## Limites
- Si l'embedding échoue après `add_document`, le document reste sans passages (pas de suppression dans `Repository`).
- Le fichier est lu en mémoire avant le contrôle de taille.
- `alerts` = nombre de passages signalés (pas les codes).

## Écarts aux contrats de 06
- `Repository` n'expose pas la lecture de documents/passages par id : `list_documents`, `get_document`, `get_chunk` lisent `repo.engine` via `storage.schema` (SqlRepository uniquement).

## Pour comprendre
L'ingestion est une chaîne de réception de courrier : on pèse le colis (taille), on l'ouvre (lecture), on vérifie qu'on ne l'a pas déjà reçu (empreinte), on le découpe en fiches, on passe chaque fiche au détecteur de consignes piégées, on y colle une étiquette de position (vecteur) et on range le tout dans le classeur du bon dossier. Le portier (appartenance) répond « inconnu » à qui n'y a pas droit.
