# Lot R1 — Revue d'intégration et durcissement

## Fait
Parcours réel (uvicorn, SQLite, modèle déterministe, jetons) rejoué en HTTP : comptes → dossier → import (TXT/DOCX/PDF/PPTX) → recherche → constats → feuille de route → ToR (6 sections, TPV 1,0) → relecture → approbation par un second compte → export DOCX/PPTX. Sondage de ~50 cas d'erreur (401, 403, 404, 409, 415, 422, doublon, fichier vide, auto-approbation, état non brouillon) : tous conformes, sauf les bugs ci-dessous.

## Bugs trouvés et corrigés (tests : `backend/tests/api/test_r1_regressions.py`)
1. **CORS absent** : le front (`:3000`) ne pouvait pas appeler l'API (`:8000`) dans un navigateur (préflight 405). Ajout du réglage `CORS_ORIGINS` (défaut localhost/127.0.0.1:3000 ; vide = désactivé) et exposition de `Content-Disposition` / `X-Content-SHA256` pour l'export.
2. **Format d'erreur de 06 §6 non respecté** pour 401, 422, 404/405 de routage (corps `{"detail": …}`) : gestionnaires globaux → `{"error": {"code", "message"}}` (codes `UNAUTHENTICATED`, `VALIDATION_ERROR`, `NOT_FOUND`…).
3. **Pas de modèle utilisable sans GPU** : `LLM_PROVIDER=fake` produit du texte générique qui échoue à la vérification. Ajout de `LLM_PROVIDER=demo` (`app/llm/demo.py`) : recopie et cite des phrases réelles des passages.
4. **Aucun moyen de créer un compte** (`docs/10` : « script à fournir ») : `backend/scripts/create_user.py` (mot de passe ≥ 12 car., via `CADRAGE_PASSWORD`), copié dans l'image Docker ; `docs/10` §2.4 mis à jour.
5. **Console Windows cp1252** : le script de démo plantait à l'affichage de caractères non représentables ; sortie en `errors="replace"`.

## Ajout
`backend/scripts/demo_parcours.py` : lance un serveur jetable (ou `--url` + comptes) et rejoue les 10 étapes (~3 s). Test de bout en bout (marqueur `slow`).

## Vérifié sans écart
Routes du front = routes du back (31 appels) ; migration Alembic 0001/0002 = schéma SQLAlchemy (SQLite) ; scripts `.ps1` du dossier `deploy/` : syntaxe valide.
