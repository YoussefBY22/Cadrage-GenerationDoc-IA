## Pour comprendre
Les contrats sont le plan d'un immeuble : avant que quatre équipes construisent chacune un étage, on fixe l'emplacement des gaines et des escaliers. `discover_routers` est un tableau d'affichage : chaque lot y accroche sa fiche `routes_*.py` sans toucher au hall d'entrée (`main.py`).

## Notions pour le glossaire
- Contrat : signature ou modèle de données qu'un lot ne change pas sans le signaler.
- TPV : taux de phrases vérifiées = phrases « verified » / phrases totales.
- Routeur découvert : module `routes_*.py` inclus automatiquement par l'application.
