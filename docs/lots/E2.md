# Lot E2 — Données de démonstration et Power BI

## Fait
- `app/dw/demo.py` : `generate_demo(op_engine, *, seed=42, clients=5, missions=12, days=90, start=2026-09-01)` écrit, via `SqlRepository`, utilisateurs, dossiers « [DÉMO] … » (`is_demo`), documents/passages, runs, retrievals, vérifications, versions et transitions ; puis `run_etl` (complet) et `create_views`. Sans effet si des dossiers démo existent. CLI : `python -m app.dw.demo --seed 42`.
- `app/dw/export_csv.py` : une CSV par vue (7), UTF-8 avec BOM, `;` + virgule décimale (`--locale fr`, défaut) ou `,` + point (`--locale en`). CLI : `python -m app.dw.export_csv --out bi/export/`.
- `bi/README.md` (pas à pas Power BI Desktop : connexion CSV ou PostgreSQL `bi_reader`, relations, mesures, 5 pages, avertissement Power BI Service/C1, points à vérifier), `bi/measures.dax` (8 mesures de 07 §6), `bi/pages.md`, `bi/metabase.md` (connexion + 5 questions SQL), `bi/.gitignore` (`export/`).
- `deploy/docker-compose.bi.yml` : service `metabase`, profil `bi`, réseaux `internal` + `edge` (port local 127.0.0.1 seulement), télémétrie coupée ; aucune image téléchargée.

## Testé

Tests : même graine → mêmes KPI (autre graine → autres) ; `is_demo` vrai sur toutes les tables `dw` qui le portent ; TPV C 0,86 > B 0,82 > D 0,78 > A 0,35 ; distributions plausibles (retouche moyenne 0,2–0,4, refus en relecture, alertes) ; CSV relues = vues (en-têtes, nombre de lignes, valeurs, BOM, virgule/point, NULL vide).
Jeu par défaut (graine 42) : 12 dossiers, 36 documents, 144 passages, 17 livrables, 109 runs, 33 versions, 38 transitions, ~2 470 lignes d'entrepôt.

## Limites
- Power BI, Metabase, Docker et PostgreSQL non essayés : relations, mesures DAX, import CSV, pilote Npgsql, `bi_reader`, image Metabase sont marqués **[À VÉRIFIER]** (lot T6).
- Le TPV suit la cible par « diffusion d'erreur » (la part cumulée de phrases vérifiées colle à 0,35/0,82/0,86/0,78) : l'ordre C > B > D > A est garanti, mais ce n'est pas un tirage indépendant. Citations valides ≈ 0,87/0,97/0,98/0,95 (A/B/C/D) : valeurs inventées.
- Les timestamps sont réécrits après coup (le dépôt date « maintenant ») ; le relecteur possède quelques dossiers démo car l'ETL ne marque « démo » que les utilisateurs propriétaires.
- Les mesures « délai médian » et « refus en relecture » de la page 4 sont à créer à la main (formules dans `bi/pages.md`).

## Écarts aux contrats
- `generate_demo` ajoute `create_views` après l'ETL et renvoie aussi `dw_rows` ; elle n'est pas rejouable (elle sort sans rien écrire si une démo existe).
- La démo utilise `embedding_dim` des réglages pour les vecteurs.

## Pour comprendre
Le générateur raconte une fausse activité de 3 mois (missions, documents, générations, relectures) avec des chiffres choisis d'avance, l'écrit dans la base comme le ferait l'application, puis laisse l'ETL la ranger dans l'entrepôt : on teste ainsi toute la chaîne et on a de quoi remplir un tableau de bord sans client. L'export CSV est la porte de secours quand il n'y a pas de base PostgreSQL.
