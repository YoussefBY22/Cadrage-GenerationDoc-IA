## Pour comprendre
Le score, c'est une note de concours : chaque matière (critère) est ramenée sur 0–1, les matières « moins c'est mieux » (coût, risque) sont retournées, puis pondérées par leur coefficient. Le graphe est un planning de chantier : on ne pose pas le toit avant les murs (tri topologique), et le chemin critique est la file de tâches la plus longue qui fixe la durée totale.
