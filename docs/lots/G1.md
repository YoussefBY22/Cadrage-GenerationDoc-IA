## Pour comprendre
Le serveur est un bureau sans ligne téléphonique sortante : l'API, la base et le modèle travaillent dans une pièce fermée. Le proxy est le guichet : il reçoit les visiteurs et transmet les dossiers à l'intérieur, mais n'appelle jamais dehors. Le paquet hors ligne est une valise scellée (empreintes) apportée en main propre.

## Notions pour le glossaire
- Réseau interne Docker : réseau sans passerelle vers l'extérieur.
- Proxy inverse : serveur qui reçoit les requêtes et les relaie vers les services internes.
- Paquet hors ligne (bundle) : dossier autonome (images, dépendances, empreintes) installable sans Internet.
